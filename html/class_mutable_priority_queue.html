Detailed Description

template<class T>
class MutablePriorityQueue< T >

Fila de prioridade mutável baseada em min-heap binário.

Requer que a classe T tenha: (i) campo acessível int queueIndex; (ii) operator< definido. Utilizada pelo algoritmo de Dijkstra.
