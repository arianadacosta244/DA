Detailed Description

Motor de atribuição baseado em Max-Flow (Edmonds-Karp).

Rede (GenerateAssignments == 1, domínios primários): Source → Tópico(t) cap = INF Tópico(t) → Reviewer(r) cap = MaxReviewsPerReviewer (se r.primary == t) Reviewer(r) → Submission(s) cap = 1 (se s.primary == t) Submission(s) → Sink cap = MinReviewsPerSubmission

Complexidade Edmonds-Karp: O(V * E^2)
